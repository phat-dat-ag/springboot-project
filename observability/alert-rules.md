# Phase 5 alert reference

Generated by `build-phase5.py`. All rules evaluate every minute, recover after a one-minute keep-firing period, and have execution-error behavior `Error`. External delivery is muted.

## ServiceDown

UID: `sb5-service-down`; severity **critical**; pending **2m**; no-data **NoData**. Condition: `lt 1`.

```promql
up{job="springboot"}
```

Private scrape endpoint failed continuously for 2m; not proof the public API is down.

Investigate: Check target lastError, API readiness, private port 9091 and container health.

## High5xxErrorRate

UID: `sb5-high5xx-error-rate`; severity **critical**; pending **5m**; no-data **OK**. Condition: `gt 0.05`.

```promql
(sb:http_5xx:rate5m / (sb:http_requests:rate5m > 0)) and on (service,environment) (sum by (service,environment) (increase(http_server_requests_seconds_count{uri!~"/actuator/.*"}[5m])) >= 100)
```

>5% server errors with at least 100 requests/5m; excludes Actuator.

Investigate: Open HTTP Performance, compare routes/status, then errors and sampled traces.

## HighHTTPErrorRatio

## HighHeapUsage
